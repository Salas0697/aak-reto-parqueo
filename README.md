# AAK Reverse Parking Experience

Interactive workplace-awareness microexperience developed for **AAK Colombia**.

## Overview

This project transforms a simple parking guideline into a short interactive experience. The user completes a reverse-parking challenge using steering and vehicle controls and then receives four practical coexistence reminders.

The experience was designed for mobile use and internal communication, combining **behavioral design, interaction and corporate communication** in a lightweight web format.

## Purpose

The objective is not only to communicate parking rules, but to create a brief moment of participation before presenting the key messages. The interaction is intended to improve attention, recall and relevance compared with a conventional static communication.

## Experience flow

1. Complete the reverse-parking challenge.
2. Receive four workplace parking reminders.
3. Finish the experience with a concise behavioral takeaway.
