# Reto de parqueo AAK

Microexperiencia móvil de convivencia para AAK Colombia.

**Tu espacio. Nuestro espacio.**

El reto invita a los colaboradores a estacionar un vehículo en reversa usando una cabrilla, acelerador y reversa. Al completar correctamente la maniobra, presenta cuatro recordatorios de convivencia:

1. Deja libre la salida.
2. Puertas con cuidado.
3. Hasta el fondo y derecho.
4. Si bloqueas, responde.

## Publicación

La experiencia es una web estática autocontenida en `index.html` y está preparada para publicarse con GitHub Pages desde la rama `main`, carpeta raíz `/`.
